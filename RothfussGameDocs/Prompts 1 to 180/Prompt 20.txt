─────────────────────────────────────
clampReputation(value)
─────────────────────────────────────

- Round down with Math.floor before clamping if needed
- negative becomes 0
- over 100 becomes 100
─────────────────────────────────────
getReputationValue(state, axis)
─────────────────────────────────────
- Return the numeric value for the requested main axis
─────────────────────────────────────
setReputationValue(state, axis, value)
─────────────────────────────────────
- Return a new PlayerState with the requested axis set to the clamped value
- Do not mutate the input state
─────────────────────────────────────
adjustReputation(state, axis, delta)
─────────────────────────────────────
- Return a new PlayerState with the requested axis adjusted by delta
- Clamp result 0–100
- Do not mutate the input state
─────────────────────────────────────
getNpcTrust(state, npcId)
─────────────────────────────────────
- Return state.reputation.npc_trust[npcId] if present
- Otherwise return 50
This preserves existing MVP assumptions.
─────────────────────────────────────
setNpcTrust(state, npcId, value)
─────────────────────────────────────
- Return a new PlayerState with npc_trust[npcId] set to the clamped value
- Do not mutate the input state
─────────────────────────────────────
adjustNpcTrust(state, npcId, delta)
─────────────────────────────────────
- Return a new PlayerState with npc_trust[npcId] adjusted by delta
- Clamp result 0–100
- Do not mutate the input state
