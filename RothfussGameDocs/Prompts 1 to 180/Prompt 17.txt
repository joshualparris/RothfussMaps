ENGINE - src/engine/conditionEngine.ts
═══════════════════════════════════════

Implement and export:

  MIN_CONDITION = 0
  MAX_CONDITION = 100

  HUNGER_INCREASE_PER_STEP = 6
  FATIGUE_INCREASE_PER_STEP = 4

  MEAL_HUNGER_RECOVERY = 30
  SLEEP_FATIGUE_RECOVERY = 50
  SLEEP_HUNGER_INCREASE = 8

  clampCondition(value: number): number

  getHungerLabel(hunger: number): string
  getFatigueLabel(fatigue: number): string

  applyTimePassageNeeds(
    state: PlayerState,
    steps: number
  ): PlayerState

  applyMealRecovery(
    state: PlayerState
  ): PlayerState

  applySleepRecovery(
    state: PlayerState
  ): PlayerState

Rules:

─────────────────────────────────────
clampCondition(value)
─────────────────────────────────────

- Clamp to integer 0-100
- Negative becomes 0
- Over 100 becomes 100
- Round down with Math.floor before clamping if needed

─────────────────────────────────────
getHungerLabel(hunger)
─────────────────────────────────────

Use these deterministic bands:

  0-20   -> "well-fed"
  21-50  -> "peckish"
  51-80  -> "hungry"
  81-100 -> "starving"

Return those exact strings.

─────────────────────────────────────
getFatigueLabel(fatigue)
─────────────────────────────────────

Use these deterministic bands:

  0-20   -> "rested"
  21-50  -> "tired"
  51-80  -> "weary"
  81-100 -> "exhausted"

Return those exact strings.

─────────────────────────────────────
applyTimePassageNeeds(state, steps)
─────────────────────────────────────

Rules:
- steps <= 0 returns state unchanged
- For each step:
    hunger += HUNGER_INCREASE_PER_STEP
    fatigue += FATIGUE_INCREASE_PER_STEP
- Clamp both values 0-100
- Return a new PlayerState
- Do not alter warmth here
- Do not alter any unrelated fields

This helper standardises the existing MVP assumption that time passing
slowly worsens hunger and fatigue.

─────────────────────────────────────
applyMealRecovery(state)
─────────────────────────────────────

Rules:
- Reduce hunger by MEAL_HUNGER_RECOVERY
- Clamp 0-100
- Return a new PlayerState
- Do not change fatigue here
- Do not change warmth here

─────────────────────────────────────
applySleepRecovery(state)
─────────────────────────────────────

Rules:
- Reduce fatigue by SLEEP_FATIGUE_RECOVERY
- Increase hunger by SLEEP_HUNGER_INCREASE
- Clamp both 0-100
- Return a new PlayerState
- Do not change warmth here
- Do not alter any unrelated fields

This helper represents the fact that sleep restores energy but time
passes and the player wakes needing food again.
