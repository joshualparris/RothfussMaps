Implement and export:

-------------------------------------
canEnterEolian(state: PlayerState): boolean
-------------------------------------

Return true only if:
  state.time_of_day is 'evening' or 'night'

Otherwise false.

-------------------------------------
calculateAuditionScore(state: PlayerState): number
-------------------------------------

Return a deterministic score 0-100.

Formula:
  score = 35

  if player has an inventory item with id === 'lute':
    score += 15
  else:
    return 0

  if state.reputation.eolian_standing >= 40: score += 10
  else if state.reputation.eolian_standing >= 30: score += 5

  if state.reputation.university_social >= 50: score += 3

  if state.fatigue >= 70: score -= 15
  else if state.fatigue >= 40: score -= 5

  if state.hunger >= 70: score -= 10
  else if state.hunger >= 40: score -= 4

  if state.warmth < 40: score -= 5
  if state.injuries.length > 0: score -= 10

  Clamp result 0-100.

This score is engine truth. Do not make it random.

-------------------------------------
auditionForPipes(
  state: PlayerState,
  db
): { message: string; newState: PlayerState }
-------------------------------------

Rules:
  - Player must be at eolian_floor
  - canEnterEolian(state) must be true
  - Player must have a lute in inventory
  - If state.eolian_state.has_talent_pipes is already true:
      return blocked line
      state unchanged
  - If state.eolian_state.last_audition_day === state.day_number:
      return blocked line
      state unchanged

On blocked:
  - choose line from EOLIAN_AUDITION_BLOCKED
  - state unchanged

On attempt:
  - score = calculateAuditionScore(state)

Success threshold:
  - if score >= 50:
      has_talent_pipes = true
      last_audition_day = state.day_number
      eolian_standing += 15 (clamp 100)
      university_social += 2 (clamp 100)
      fatigue += 5 (clamp 100)
      hunger += 2 (clamp 100)
      return success line from EOLIAN_AUDITION_SUCCESS

Failure:
  - has_talent_pipes stays false
  - last_audition_day = state.day_number
  - eolian_standing += 1 (clamp 100)
  - fatigue += 4 (clamp 100)
  - hunger += 2 (clamp 100)
  - return fail line from EOLIAN_AUDITION_FAIL

Do not award money here.

-------------------------------------
playAtEolian(
  state: PlayerState,
  db
): { message: string; newState: PlayerState }
-------------------------------------

Rules:
  - Player must be at eolian_floor
  - canEnterEolian(state) must be true
  - state.eolian_state.has_talent_pipes must be true
  - state.eolian_state.performances_today must be 0
  - Player must have a lute in inventory

If blocked:
  - return a short in-world line
  - state unchanged

On success:
  - call advanceTime(state, 1)
  - then apply:
      eolian_state.performances_today += 1
      reputation.eolian_standing += 2 (clamp 100)
      reputation.university_social += 1 (clamp 100)
      fatigue += 10 (clamp 100)
      hunger += 5 (clamp 100)
  - return line from EOLIAN_PLAY_LINES

No direct money reward.
The Eolian is not Anker's.

-------------------------------------
isLutePresent(state: PlayerState): boolean

Return true if inventory contains item id 'lute' with quantity >= 1.
