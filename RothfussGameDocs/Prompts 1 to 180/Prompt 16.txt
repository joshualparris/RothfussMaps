ECONOMY RULES - update src/engine/economy.ts
═══════════════════════════════════════

Do not refactor the entire file.
Only standardise and extend what is already there.

Add and export these constants:

  ANKERS_ROOM_COST_DRABS = 20   // 2 jots
  BASIC_MEAL_COST_DRABS = 4     // modest student meal
  LOW_FUNDS_WARNING_DRABS = 15  // 1 jot, 5 drabs
  CRITICAL_FUNDS_WARNING_DRABS = 5

Rules:
- Keep these as simple constants in economy.ts
- Do not add dynamic pricing
- Do not add random modifiers

Also implement and export:

  getFundsWarning(drabs: number): string | null

Rules for getFundsWarning(drabs):
- if drabs <= CRITICAL_FUNDS_WARNING_DRABS:
    return a brief warning line indicating the player is nearly out of money
- else if drabs <= LOW_FUNDS_WARNING_DRABS:
    return a brief warning line indicating money is running short
- else:
    return null

Tone:
- practical
- grounded
- not melodramatic
- no meta-game wording

Example acceptable warning tone:
  "You are nearly out of money."
  "Your purse is growing worryingly light."

Do not mention exact arithmetic in the warning unless naturally needed.
