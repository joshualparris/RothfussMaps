ENGINE - update src/engine/musicEngine.ts

Rules:

─────────────────────────────────────
canBuskAtAnkers(state)
─────────────────────────────────────

Return true only if:
- state.location_id === 'university_ankers'
- inventory contains item id 'lute'
- state.busking_state.busked_today === false
- state.fatigue < 85

Otherwise false.

Do not check any other conditions in this helper.

─────────────────────────────────────
calculateBuskingQuality(state)
─────────────────────────────────────

Return one of:
  'poor'
  'modest'
  'strong'

Deterministic rules only.
No randomness.

Suggested scoring model:
  start score = 0

  if state.reputation.university_social >= 50: score += 1
  if state.reputation.eolian_standing >= 40: score += 1

  if state.fatigue >= 70: score -= 2
  else if state.fatigue >= 40: score -= 1

  if state.hunger >= 70: score -= 1

  if state.injuries.length > 0: score -= 1

  if state.money_drabs < 20: score += 0
    // poverty does not improve performance; no romanticising

Map final score:
  score <= -1 -> 'poor'
  score 0..1  -> 'modest'
  score >= 2  -> 'strong'

Keep it deterministic and compact.

─────────────────────────────────────
buskAtAnkers(state, db)
─────────────────────────────────────

Rules:
- If canBuskAtAnkers(state) is false:
    return blocked line from ANKERS_BUSK_BLOCKED
    state unchanged

On success:
- determine quality via calculateBuskingQuality(state)
- call advanceTime(state, 1)
- then apply deterministic earnings:

  poor:
    +2 drabs
    university_social unchanged
    eolian_standing unchanged

  modest:
    +4 drabs
    university_social +1 (clamp 100)
    eolian_standing unchanged

  strong:
    +7 drabs
    university_social +2 (clamp 100)
    eolian_standing +1 (clamp 100)

- use addMoney() from engine/currency.ts
- set:
    busking_state.busked_today = true
    busking_state.last_busk_day = newState.day_number
- increase fatigue by 8 (clamp 100)
- increase hunger by 4 (clamp 100)

Return:
- a line from the matching narration pool
- plus a short second line stating the money earned in natural language,
  using formatCurrency()
- do not auto-render the location
- do not award talent pipes
- do not change academic_standing here

Tone:
- grounded, practical
- this is decent survival work at best, not triumph

─────────────────────────────────────
resetDailyBusking(state)
─────────────────────────────────────

Rules:
- if state.busking_state.last_busk_day !== state.day_number:
    set busked_today to false
- otherwise leave unchanged
- return new state

This helper exists because day changes should reopen busking later.
