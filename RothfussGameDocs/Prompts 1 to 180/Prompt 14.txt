ENGINE - src/engine/currency.ts
═══════════════════════════════════════

Implement and export:

  DRABS_PER_JOT = 10
  JOTS_PER_TALENT = 10
  DRABS_PER_TALENT = 100

  breakdownCurrency(drabs: number): {
    talents: number;
    jots: number;
    drabs: number;
  }

  formatCurrency(drabs: number): string

  canAfford(currentDrabs: number, costDrabs: number): boolean

  spendMoney(
    currentDrabs: number,
    costDrabs: number
  ): { success: boolean; remainingDrabs: number }

  addMoney(
    currentDrabs: number,
    amountDrabs: number
  ): number

Rules:

─────────────────────────────────────
breakdownCurrency(drabs)
─────────────────────────────────────

- Input is total drabs as an integer
- Clamp negative input to 0 before processing
- Return whole talents, remaining jots, remaining drabs
- Example:
    125 -> { talents: 1, jots: 2, drabs: 5 }

─────────────────────────────────────
formatCurrency(drabs)
─────────────────────────────────────

- Use breakdownCurrency()
- Output examples:
    0   -> "nothing"
    7   -> "7 drabs"
    10  -> "1 jot"
    15  -> "1 jot, 5 drabs"
    100 -> "1 talent"
    125 -> "1 talent, 2 jots, 5 drabs"
    300 -> "3 talents"
- Omit zero-value denominations
- Use singular/plural correctly:
    1 drab / 2 drabs
    1 jot / 2 jots
    1 talent / 2 talents
- Deterministic only

─────────────────────────────────────
canAfford(currentDrabs, costDrabs)
─────────────────────────────────────

- Return false if costDrabs < 0
- Return currentDrabs >= costDrabs otherwise

─────────────────────────────────────
spendMoney(currentDrabs, costDrabs)
─────────────────────────────────────

- If costDrabs < 0:
    return success: false, remainingDrabs: currentDrabs
- If currentDrabs < costDrabs:
    return success: false, remainingDrabs: currentDrabs
- Otherwise:
    return success: true, remainingDrabs: currentDrabs - costDrabs

Do not allow negative remaining money.

─────────────────────────────────────
addMoney(currentDrabs, amountDrabs)
─────────────────────────────────────

- If amountDrabs <= 0:
    return currentDrabs
- Otherwise return currentDrabs + amountDrabs

Do not mutate PlayerState here.
Pure functions only.
