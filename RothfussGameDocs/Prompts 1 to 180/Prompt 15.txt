GOAL OF THIS PROMPT
═══════════════════════════════════════

By the end of Prompt 15, the player should be able to:

  - type `tuition` or `check tuition` and see what is owed
  - type `pay tuition` and pay it if they can afford it
  - fail to pay if they do not have enough money
  - cross the deadline and have tuition become overdue
  - suffer a one-time overdue consequence to reputation/standing
  - continue play with the overdue state visible until paid

The codebase should have one authoritative tuition module used by all
current tuition-related logic.

═══════════════════════════════════════
ENGINE - src/engine/tuitionEngine.ts
═══════════════════════════════════════

Implement and export:

  getTuitionStatusText(state: PlayerState): string

  canPayTuition(state: PlayerState): boolean

  payTuition(state: PlayerState): {
    message: string;
    newState: PlayerState;
  }

  checkTuitionDeadline(state: PlayerState): {
    message: string | null;
    newState: PlayerState;
  }

Rules:

─────────────────────────────────────
getTuitionStatusText(state)
─────────────────────────────────────

Return a clean in-world status string describing:
- amount owed (formatted currency)
- due day
- whether already paid
- whether overdue

Use formatCurrency from engine/currency.ts.

Examples of tone:
- factual, concise, in-world enough to fit the rest of the CLI
- no raw JSON
- no game jargon like "quest" or "objective"

Suggested output shape:
  "Tuition owed: 3 jots. Due on day 14. Status: unpaid."
  "Tuition owed: nothing. Status: paid."
  "Tuition owed: 3 jots. Due on day 14. Status: overdue."

─────────────────────────────────────
canPayTuition(state)
─────────────────────────────────────

Return true only if:
- tuition_state.paid is false
- state.money_drabs >= tuition_state.amount_drabs

Otherwise false.

─────────────────────────────────────
payTuition(state)
─────────────────────────────────────

Rules:
- If tuition_state.paid is already true:
    return a brief line saying tuition is already settled
    state unchanged
- If player cannot afford payment:
    return a brief line saying they do not have enough money
    state unchanged
- Otherwise:
    deduct tuition_state.amount_drabs using spendMoney() from engine/currency.ts
    set:
      tuition_state.paid = true
      tuition_state.overdue = false
    leave overdue_penalty_applied unchanged
    return a brief in-world line acknowledging the payment

Do not change any other systems here.

─────────────────────────────────────
checkTuitionDeadline(state)
─────────────────────────────────────

Rules:
- If tuition_state.paid is true:
    return message null, state unchanged
- If state.day_number <= tuition_state.due_on_day:
    return message null, state unchanged
- If tuition is already overdue and overdue_penalty_applied is true:
    return message null, state unchanged
- Otherwise:
    set:
      tuition_state.overdue = true
      tuition_state.overdue_penalty_applied = true

    apply a one-time overdue penalty:
      reputation.academic_standing -= 5 (clamp min 0)
      reputation.university_social -= 2 (clamp min 0)

    return a brief line making clear tuition has gone overdue and this
    has affected the player's standing

Rules for tone:
- practical, institutional, unpleasant
- not melodramatic
- no invented hearing scene yet
