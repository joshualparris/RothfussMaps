─────────────────────────────────────
containsForbiddenMysteryPhrase(text)
─────────────────────────────────────
Return a list of human-readable reason strings if the text contains any
forbidden mystery-resolution phrases.
Check case-insensitively for these phrases or close equivalents:
"  ""the chandrian are"""
"  ""the amyr are"""
"  ""denna's patron is"""
"  ""the doors of stone are"""
"  ""the true name of"""
"  ""the secret of the chandrian"""
"  ""the amyr's true purpose"""
"  ""it is revealed that the chandrian"""
"  ""it is revealed that the amyr"""
"  ""the answer to the doors of stone"""
"  ""denna was working for"""
"  ""his true name is"""
"  ""her true name is"""
Rules:
- return compact reason strings, e.g.
"    ""forbidden mystery phrase: 'Denna's patron is'"""
- do not try to do fuzzy AI interpretation
- use deterministic string matching only
- case-insensitive
- no regex that is too broad or fragile
─────────────────────────────────────
containsSceneContradiction(text, context)
─────────────────────────────────────
Return a list of human-readable reason strings if the narration
contradicts the supplied scene context in obvious ways.
Check only these concrete contradictions:
1. Visible NPC contradiction
   - If context.npc_summary.names is empty and the text claims a named
     NPC is present from this known set:
       Simmon, Wilem, Anker, Kilvin, Ambrose, Deoch, Stanchion
   - If context.npc_summary.names is non-empty and the text introduces
     one of those named NPCs who is not in the visible list
2. Exit contradiction
   - If the text mentions directions as obvious exits that are not in
     context.location_summary.exits
   - Only check directions:
       north, south, east, west, up, down, enter, out
3. Location-name contradiction
   - If the text explicitly names a different current seeded location
     than context.location_summary.name
   - Seeded location names to check against:
       the Mains
       the Artificery
       the Archives, outer steps
       the Stacks
       the Medica
       Kvothe's room, the Mews
       the Mews corridor
       the University courtyard
       Anker's inn
       the Fishery, outer workspace
       the Mains, lecture hall
       the riverside road
       Stonebridge
       the square before the Eolian
       outside the Eolian
       the Eolian
Rules:
- only flag obvious contradictions
- do not attempt deep semantic contradiction detection
- do not inspect mood/tone/style here
- do not treat silence as contradiction
─────────────────────────────────────
checkLoreSafety(text, context)
─────────────────────────────────────
Combine both checks:
- forbidden mystery phrase check
- scene contradiction check
Return:
  {
    isSafe: reasons.length === 0,
    reasons
  }
Deterministic only.
No randomness.
No side effects.
