# Extract Building Evidence

Use this workflow when gathering or revising canon evidence for one University building.

## Inputs

- Building id, for example `archives`
- Source texts or existing evidence files
- Current building brief, if one exists

## Output

Update or draft evidence rows with:

- source
- quote or paraphrase
- location reference
- claim
- building or zone
- certainty: `canon`, `implied`, or `reconstructed`
- contradiction notes

## Rules

- Do not jump from evidence directly to floor geometry.
- Preserve contradictions.
- Mark absence of evidence as uncertainty, not freedom to invent.
- Prefer narrow claims over broad interpretation.
