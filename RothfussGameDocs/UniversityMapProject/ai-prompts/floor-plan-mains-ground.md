## PLACEMENT DISCIPLINE
- Decide which wall faces the main approach or corridor before placing doors.
- Put the primary door where the known route naturally enters the floor, not at a default centered position.
- Place stairs where the evidence requires vertical movement; do not add symmetrical stair pairs unless the brief supports them.
- Use exterior windows only on true perimeter walls and only if the building shell permits them.
- Let one main circulation spine organize the plan, then branch smaller rooms or alcoves from it.
- Place large fixed elements such as counters, shelves, hearths, baths, stages, or worktables where their function is clearest and where they do not block the main path.
- If a room count or doorway is uncertain, keep unlabeled service or corridor space instead of inventing many named rooms.
