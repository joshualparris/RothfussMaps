# Next Phase Plan

## Goal

Move Crydee from an evidence-led but flat blockout into a more source-accurate and actually playable Castle Crydee prototype.

## Phase 1: Restore Playability

- Fix stairs that are currently impossible or unreliable to climb.
- Check player collision against all vertical-link ramps.
- Add safer landings and less brittle stair geometry.
- Re-test cellar, gatehouse walk, and magician tower ascent/descent.

## Phase 2: Build The Site Relationship

- Add town-below, approach road, and gate arrival sequence.
- Add topography so the castle sits above the town.
- Add coastal, bluff, and forest context where the book supports it.
- Keep all site-shape uncertainty explicitly reconstructed.

## Phase 3: Rebuild The Strongest Canon Sequence

- Rebuild the great gate and smaller inset door.
- Rebuild the courtyard to keep-stairs sequence.
- Add balcony-over-courtyard logic.
- Make the great hall read as a court room, not just a named box.

## Phase 4: Rebuild The Interior Hero Route

- Rebuild the great hall -> service corridor -> kitchen -> storage -> cellar/tower route.
- Improve the magician's tower so it feels quiet, vertical, and kitchen-linked.
- Improve the Princess's garden with steps, screening, and bench logic.

## Phase 5: Rebuild Defensive Architecture

- Add wall-walks, battlements, parapets, and wall stairs.
- Preserve west wall and east wall as real orientation anchors.
- Decide whether siege-state Crydee now needs its own versioned target.

## Detailed Task Source

Use `docs/SOURCE_ACCURACY_TASKLIST.md` as the authoritative Codex backlog for this phase.

## Stop Condition

Do not call the current rebuild “source-accurate” until:

- the vertical routes are walkable
- the site relationship is visible in-game
- the gate/courtyard/keep sequence feels like the book
- the kitchen-service-tower route is readable
- defensive walls are more than symbolic boxes
